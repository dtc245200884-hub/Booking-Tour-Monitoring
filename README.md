# Booking Tour Monitoring

## Công nghệ
- Docker Compose
- Prometheus
- Node Exporter
- Grafana

## Truy cập
- Prometheus: http://localhost:9091
- Grafana: http://localhost:3002
+ Tài khoản : admin
+ Mật khẩu : admin
- Node Exporter: http://localhost:9100/metrics

## Khởi chạy
docker compose up -d

## Kiểm tra
docker compose ps
